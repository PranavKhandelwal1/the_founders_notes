# Audit and upgrade, 25 November 2026

Method: read the whole project, compared it to the live site (they matched), ran every one of the 66 routes in Chromium at 1280px and 375px, with and without the browser features the build step lacks, and checked titles, descriptions, canonicals, headings, structured data, links and images. Baseline before changes: 0 errors. After: 0 errors.

## Issues found

### Critical
- **No category system.** Stories had free-form tags only, so the five sections of the publication did not exist. Fixed.
- **Missing trust pages.** No editorial policy, submission guidelines, terms or sponsored-content disclosure, while the publication also sells web services. Fixed (drafts, see "Needs your review").

### High
- **19 thin tag pages in the sitemap** (one story each). The code comment said "2+ stories" but did not enforce it. Fixed: `noindex` and removed from the sitemap; URLs still work.
- **Incomplete social metadata.** Only `twitter:card` existed; no Twitter title, description or image, no `og:image:alt`. Fixed on every page.
- **No Get featured call to action on story pages.** The code looked for a box that was never rendered. Fixed.
- **Colours:** this version keeps the live site's colours (white, soft grey, dark ink, green accent). Only the type and corner sizes changed.
- **Body text used a serif.** The brief asks for sans body text. Fixed.
- **Homepage copy described only yoga and martial arts.** Broadened to match the stated scope.

### Medium
- Story pages showed no visible author although the structured data named one. Added a byline.
- Q&A headings in articles skipped a heading level (h1 to h3). Fixed.
- "Disciplines" statistic counted distinct first tags, which is not meaningful. Replaced by categories.
- Over-rounded cards (24px), pill buttons, tracked all-caps labels and a third font family. Calmed.
- Services was in the main navigation of a publication. Moved to the footer (one line to revert in `index.html`).
- Footer lacked policy links. Rebuilt in four columns.
- No RSS feed. Added.
- Analytics lacked share, Instagram, website and Get featured events. Added.

### Low (not done, see Remaining)
- Images are not served in several sizes or WebP.
- All story text loads on every page (about 90 KB of data).
- CSS is not split per page (about 90 KB, mostly unused on any given page).
- Google Fonts is a third-party request.
- Newsletter has no sending service connected.

## Deploy
1. Copy the files into your repository (same folder layout) and commit.
2. Push to the branch your workflow deploys from. GitHub Actions runs `npm ci`, `node build.js` and publishes.
3. If the build stops, its message says which file and why.
4. Afterwards: open `/feed.xml` and `/sitemap.xml`, check a story with Google's Rich Results Test and a category page's source for `noindex`/`index`, and submit the sitemap in Search Console.
